# Plugins

This folder contains the code for the plugins on SuCraft.

The `forked` folder contains forked versions of plugins made by others,
with customizations for SuCraft.

The other folders (`generation-1` to `generation-5`)
contain the plugins custom-made for SuCraft.

* `generation-1`\
  Plugins made mostly around 2011-2012.\
  These were mostly just some quick Bukkit hacks to customize things in other plugins.
* `generation-2`\
  Plugins made mostly around 2012-2019.\
  These plugins started the coherent suite of functions (homes, warps, shops, achievements etc.)
  that you know from SuCraft today.
* `generation-3`\
  Plugins made mostly around 2020-2021.\
  These plugins were a full re-make of most of the SuCraft suite
  (adding warp, shop and achievement interfaces, `/trust` and much more).
* `generation-4`\
  One plugin developed between 2021-2025.\
  The plugin was intended to become the one-and-all plugin for everything, written in Kotlin,
  but only features that do not require a database were eventually added.
* `generation-5`\
  A new attempt at the same goal as generation 4: a single one-and-all plugin for everything.\
  Most features are still in the older plugins and are slowly being moved to this newer plugin.
